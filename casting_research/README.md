# キャスティングリサーチシステム

X(Twitter)上で伸びている「商品をタレント/インフルエンサーが使っている切り抜き」を
見つけ、出演者の情報・関連素材を調べて記録し、キャスティング事例と
コンテンツ傾向をまとめるためのツール。

## できること／できないこと

- **できること**: 見つけた事例を構造化データ（`data/clips.json` / `data/talents.json`）
  として蓄積し、商品別・タレント別・コンテンツ種別・伸びた要因タグ別の集計レポート
  （Markdown）を自動生成する。X API契約済みなら、キーワード検索＋エンゲージメント数
  順の候補スクリーニングも可能（`collectors/x_api_collector.py`）。
- **できないこと**: 検索結果から「誰が映っているか（出演タレント）」を自動特定する
  ことはできない。これは引き続き人（またはClaude）が投稿内容を目視確認して判断し、
  `add-clip` で記録する必要がある。また検索はX API Recent Search の制約で
  **直近7日分**に限られる。

### WebSearchだけでの限界（検証済み）

汎用キーワードでのWebSearchでは、X上の引用連鎖のようなリアルタイム投稿はほぼ
ヒットしない（外部検索エンジンにインデックスされにくいため）ことを実際に確認済み。
精度よく検出するにはX API（有料・従量課金）が必要。

## 1回のリサーチの流れ

### X API契約済みの場合（推奨）

1. **候補をスクリーニングする**: `collectors/x_api_collector.py` でキーワード検索し、
   エンゲージメント数（いいね＋RT×2＋引用×2）順に候補を一覧表示する。
2. **投稿を目視確認する**: 添付メディアの有無・本文から、著名人の愛用シーン切り抜き
   かどうか、誰が映っているかを人（またはClaude）が確認する。
3. **出演者を特定・補強する**: 特定したタレント名で追加のWebSearchを行い、
   そのタレントの別の活動実績（SNS投稿・過去の出演）を素材として回収する。
4. **記録する**: 下記CLIで `add-talent` → `add-clip` の順に記録する。
5. **まとめる**: ある程度件数が溜まったら `report` コマンドで傾向レポートを生成する。

### X API未契約の場合（WebSearchベースの半自動リサーチ）

1. **商品を探す**: 「TikTok Shopで伸びている商品」「バズっている商品紹介」などの
   キーワードでWebSearchし、話題になっている商品を把握する。
2. **切り抜きを探す**: その商品名 + 「切り抜き」「X」「バズ」等でWebSearchし、
   タレント/インフルエンサーが商品を使用しているシーンの切り抜きポストを探す。
   前述のとおりヒット率は低いので、ニュースサイトのまとめ記事や、社内に既存の
   事例資料があればそれを起点にするほうが効率的。
3. **出演者を特定する**: 切り抜き内のタレント/インフルエンサーの名前を特定し、
   そのタレントの別の動画・画像（SNS投稿、過去の出演実績）を追加でWebSearchし、
   素材・実績として回収する。
4. **記録する**: 下記CLIで `add-talent` → `add-clip` の順に記録する。
5. **まとめる**: ある程度件数が溜まったら `report` コマンドで傾向レポートを生成する。

## セットアップ

Python 3.10以上の標準ライブラリのみで動作（追加インストール不要）。

```bash
cd casting_research
python3 cli.py --help
```

## 使い方

### X APIでの候補スクリーニング（契約済みの場合）

セットアップ:

1. https://developer.x.com/ でプロジェクト作成・支払い方法を登録（ユーザー自身の
   契約が必要。従量課金制、詳細は[公式料金ページ](https://docs.x.com/x-api/getting-started/pricing)参照）
2. Bearer Tokenを発行
3. 環境変数に設定

```bash
export X_API_BEARER_TOKEN="（取得したトークン）"
```

実行:

```bash
python3 collectors/x_api_collector.py --query "商品名 min_faves:500" --max-results 30
```

エンゲージメント数順の候補一覧が表示される（直近7日分のみ）。このツールは
`data/clips.json` に自動では書き込まない。出演タレントの目視確認は人（または
Claude）が行い、該当するものだけ下記の `add-clip` で記録する。

`--save output/candidates_YYYYMMDD.json` を付けると生データを保存できる
（`output/`はgit管理外のスクラッチ領域として使う想定）。

### タレント/インフルエンサーを登録

```bash
python3 cli.py add-talent --name "山田太郎" --x "@yamada_tv" --tiktok "@yamada.tiktok" \
  --genre "お笑いタレント" --note "バラエティ番組レギュラー"
```

### 切り抜き事例を登録

```bash
python3 cli.py add-clip \
  --product "〇〇クリーム" \
  --talent "山田太郎" \
  --url "https://x.com/example/status/123456789" \
  --brand "〇〇ブランド" \
  --platform X \
  --content-type "バラエティ出演シーンの切り抜き" \
  --hook CTA --hook FOMO \
  --engagement "いいね1.2万 / 引用RT300（ポスト本文記載の数値）" \
  --source web_search \
  --note "番組内で実際に使って驚くリアクションが切り抜かれ拡散"
```

`--hook` の候補タグ（自由記述も可。社内の購買トリガー分析フレームワークを流用）:
報酬予測 / 性能説明 / CTA / PAS / ツァイガルニク効果 / カクパ / FOMO / メロジョイ /
権威性 / ビタビタ / ハロー効果 / 三の法則 / ビフォーアフター / タゴサク構文

### 一覧確認

```bash
python3 cli.py list-clips
python3 cli.py list-clips --product "〇〇クリーム"
python3 cli.py list-clips --talent "山田太郎"
python3 cli.py list-talents
```

### 集計レポート生成

```bash
python3 cli.py report
```

`output/report_YYYYMMDD_HHMMSS.md` に、商品別ランキング・タレント別出演数・
コンテンツ種別傾向・伸びた要因タグ傾向・直近追加事例をまとめたレポートが出力される。

## データファイル

- `data/clips.json`: 切り抜き事例（商品名・タレント名・URL・コンテンツ種別・
  伸びた要因タグ・エンゲージメントメモ等）
- `data/talents.json`: タレント/インフルエンサーのプロフィール（各SNSハンドル等）

いずれも素のJSON。Excelで管理したい場合はこのJSONからCSV変換して開く運用でも良い。
